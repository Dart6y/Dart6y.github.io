## Technology

Single-file HTML with embedded CSS and a tiny JavaScript footer date. No dependencies, analytics, external fonts or trackers. Works on GitHub Pages without a build step.

## Publishing on GitHub Pages

1. Open `Settings → Pages` in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`. Save.
4. Wait for GitHub Pages to publish and visit https://dart6y.github.io/.

## Updating

Edit `index.html`, preview locally in a browser, and commit changes to `main`. Pages will automatically publish updates once enabled. Keep status labels, project metrics, claims about acceptance/publications and public URLs accurate.

## Accessibility

Keyboard-friendly navigation, a skip link, semantic headings, descriptive labels, responsive layouts and reduced-motion support.
